## Start with a small evidence set

Write questions, mark the passages that actually support each answer, and include questions the corpus cannot answer. Keep document versions and access labels with each expected passage.

## Score retrieval independently

Measure whether relevant passages appear in the first few retrieved results. Check permission boundaries and separate ranking failures from indexing failures.

## Check claims against citations

Break each answer into claims and verify that each cited passage supports the associated claim. Track abstention separately so the system can improve at recognizing missing evidence.
